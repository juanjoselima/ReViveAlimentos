# ReVive Alimentos

Sistema de coordinación para el rescate y la redistribución de excedentes alimentarios (Programación II, UDLA, Paralelo 15, Grupo 37).

Entregable 2: proyecto en modo consola, escrito en Java con Programación Orientada a Objetos.

## Estructura

- `src/modelo`: entidades del problema (Oferta, Donante, Receptor, Asignacion, Retiro, Entrega, Incidente, etc.).
- `src/negocio`: reglas de negocio de cada módulo (M1 a M5).
- `src/interfaz`: menús de consola.

## Cómo ejecutar

1. Abrir la carpeta del proyecto en IntelliJ IDEA.
2. Ejecutar la clase `interfaz.MenuPrincipal`.
3. Responder S para cargar los datos de demostración.
