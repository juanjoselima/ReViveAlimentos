# ReVive Alimentos

Sistema de coordinación para el rescate y la redistribución de excedentes alimentarios (Programación II, UDLA, Grupo 37).

Entregable 2: proyecto en modo consola, escrito en Java con POO.

- Paquetes: `modelo` (entidades), `negocio` (reglas de cada módulo), `interfaz` (menús de consola).
- Clase principal: `interfaz.MenuPrincipal`.
- Al iniciar, el programa pregunta si se cargan los datos de demostración.
- Diagramas UML: carpeta `docs/`.
