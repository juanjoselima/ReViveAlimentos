# ReVive Alimentos

Sistema de coordinación para el rescate y la redistribución de excedentes alimentarios (Programación II, UDLA, Paralelo 15, Grupo 37).

Entregable 2: proyecto en modo consola, escrito en Java con Programación Orientada a Objetos.

## Estructura

- `src/modelo`: entidades del problema (Oferta, Donante, Receptor, Asignacion, Retiro, Entrega, Incidente, Vehiculo, RutaRetiro, etc.).
- `src/negocio`: reglas de negocio de cada módulo (M1 a M6).
- `src/interfaz`: menús de consola.

## Módulos

- M1. Donantes, zonas y ofertas (RF-01 a RF-04)
- M2. Evaluación y prioridad (RF-05 a RF-08)
- M3. Receptores y asignaciones (RF-09 a RF-12)
- M4. Retiros, entregas e incidentes (RF-13 a RF-16)
- M5. Parámetros, indicadores y trazabilidad (RF-17 a RF-20)
- M6. Planificación de rutas de retiro (RF-21 a RF-24), módulo adicional para la exoneración del examen práctico

## Cómo ejecutar

1. Abrir la carpeta del proyecto en IntelliJ IDEA.
2. Ejecutar la clase `interfaz.MenuPrincipal`.
3. Responder S para cargar los datos de demostración.
